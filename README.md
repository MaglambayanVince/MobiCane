# MobiCane – Smart Assistive Mobility and Indoor Positioning System

MobiCane is an ESP32-based smart assistive mobility system designed to support visually impaired individuals through obstacle detection, indoor positioning, and tracking.

## Features

- **Obstacle Detection:** Uses an ultrasonic sensor and camera to help detect obstacles.
- **Indoor Positioning:** Uses four ESP32-powered BLE beacons and RSSI measurements to estimate the user's location.
- **Tracking Interface:** Displays location and tracking information through a web interface.
- **Assistive Feedback:** Integrates a speaker, microphone, OLED display, magnetic compass, and GSM module.
